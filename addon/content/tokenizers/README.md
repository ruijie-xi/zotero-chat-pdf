# Bundled DeepSeek V4 tokenizer

Source: the offline tokenizer linked by https://api-docs.deepseek.com/quick_start/token_usage/,
downloaded from https://cdn.deepseek.com/api-docs/deepseek_v4_tokenizer.zip on 2026-09-28.

- `deepseek-v4.json`: SHA-256 `89085f12ef79460ac5f66d1119325ddfc694b4ab209d80bbd81d35f081dc9614`
- `deepseek-v4-config.json`: SHA-256 `841f8cf146e3f0ad1082594a31f68ecf7608c20467ef355081333d85bbaeb1cb`

The vocabulary/model section is identical to the MIT-licensed official
`deepseek-ai/DeepSeek-V4-Flash` Hugging Face repository as checked on the same date.
The API download's added-token list differs; the API version is retained here.
`LICENSE-deepseek.txt` preserves the official model repository license.

Text fixtures in `tests/fixtures/deepseek-v4-tokens.json` were generated by the
Rust-backed Python `tokenizers.Tokenizer` from this exact tokenizer file, with
`add_special_tokens=False`. The Firefox runtime uses `@huggingface/tokenizers`.
The tokenizer config's historical `model_max_length` is never used as API capacity.
Actual model capacity comes from the selected endpoint/model metadata or explicit
profile overrides. Request-template totals are labeled estimates and calibrated
against provider-reported usage; no conversation text is sent to a tokenizer service.
